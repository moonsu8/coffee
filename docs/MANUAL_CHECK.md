# 직접 확인 순서: 옮기기 → 초대 → 그룹원 보기 → 반영

자동으로 확인하지 못하는 부분(Google 로그인, 실제 브라우저 두 개)을 사용자가 직접 해 보는 순서다.
각 단계 아래의 **성공 기준**이 보이면 통과다. 보이지 않으면 그 단계에서 멈추고 화면(또는 오류 문구)을 알려 달라.

## 준비
- 개발 서버: 저장소 폴더에서 `npm run dev` (`.env.local`에 테스트 프로젝트의 `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`가 있어야 한다).
- 주소는 **`http://localhost:5173/`** (127.0.0.1이 아니다. Google 로그인 허용 목록 때문이다).
- 창 두 개: **PC 일반 창 = 그룹장**, **시크릿 창 = 그룹원**. 시크릿 창은 일반 창과 저장소가 분리돼서, 따로 로그인하지 않은 다른 사람처럼 동작한다.
- 테스트 프로젝트에 `0001`~`0004`가 적용돼 있어야 한다(`docs/SUPABASE.md`의 확인 쿼리).
- 그룹장 Google 계정은 OAuth 동의 화면의 **테스트 사용자**로 등록된 것이어야 한다.

## A. 그룹장(PC 일반 창)

### A1. Google 로그인
1. 앱 → 설정 → **공유 그룹** 카드 → **Google로 로그인** → "만 14세 이상이에요" 체크 → **Google로 계속**.
2. 계정 선택(테스트 사용자) → "확인되지 않은 앱"이면 **고급 → 이동** → 계속.
- **성공:** 앱으로 돌아와 공유 그룹 카드에 "Google 계정으로 로그인돼 있어요"와 **로그아웃** 버튼이 보인다. 오류 문구가 없다.

### A2. 내 기기 그룹을 서버로 옮기기
1. 설정 → **그룹** 카드에서 옮길 그룹(예: 커피) 오른쪽의 **구름 아이콘(서버로 옮기기)**.
2. 안내(별명·메모, 백업, 확인) 확인 → **서버로 옮기기**.
- **성공:** "서버로 옮겼어요 · 서버에서 다시 읽어 내용이 같은 것을 확인했어요"가 보인다. (빨간 "일부 내용이 달라 보여요"가 뜨면 **멈추고 알려 달라**. 이 기기 사본은 지우지 않는다.)
3. 시트를 **닫기**.
- **성공:** 홈 위쪽 그룹 칩에 **"공유" 표시가 붙은 그룹**이 보이고, 그 그룹을 열면 화면 맨 위에 **"그룹장 · 저장됨 ○시"** 배너가 있다. 설정 > 그룹 카드의 원래 그룹에는 "서버로 옮김 · 서버 그룹이 보이는 동안 숨겨져요"가 붙고 홈 칩에서는 사라진다.

### A3. 초대 코드 만들기
1. 설정 → **공유 그룹** 카드 → 방금 옮긴 그룹 오른쪽 **초대** 버튼.
- **성공:** 시트에 유효 기간 **7일이 선택**돼 있고, 인원이 **그룹 멤버 수**로 채워져 있다. "코드로 참여한 사람은 보기만 할 수 있어요 · 지금 그룹원 0명"이 보인다.
2. **새 코드 만들기**.
- **성공:** 목록에 8자리 코드(예: `K7M2QX4P`), "○/○ 만료일까지 · 0/N명 참여"가 보인다. 코드에는 `0 O 1 I`가 없다.
3. 코드 옆 **안내문** 버튼(안내 문구 복사)을 누르고, 메모장 등에 붙여 넣어 본다.
- **성공:** "☕ 그룹이름 그룹에 초대해요 / 앱에서 설정 > 공유 그룹 > 초대 코드로 참여… / 초대 코드: …(○/○까지, 최대 N명) / 앱 주소: http://localhost:5173/" 4줄이 붙는다.

## B. 그룹원(시크릿 창)

### B1. 코드로 참여
1. 시크릿 창에서 `http://localhost:5173/` → 설정 → 공유 그룹 → **초대 코드로 참여**.
2. A3에서 복사한 코드를 붙여 넣고 "만 14세 이상이에요" 체크 → **참여하기**. (코드는 소문자·공백이 섞여도 된다.)
- **성공:** "○○에 참여했어요" 토스트가 뜨고, 공유 그룹 카드에 그 그룹과 **"보기 전용 · 업데이트 ○시"**가 보인다. (그룹장 화면에서 초대 시트를 다시 열면 **참여 1/N명, 그룹원 1명**으로 바뀐다.)

### B2. 보기 전용 확인
1. 홈으로 가서 위쪽 그룹 칩에서 **"공유" 표시가 붙은 그룹**을 누른다.
- **성공:** 화면 맨 위에 **"보기 전용 · 마지막 업데이트 ○시"** 배너. 당번 이름, 다음 순서, 앞으로 5번이 그룹장 화면과 같다.
- **성공(쓰기 없음):** 홈에 **[샀어요]/[기록 취소] 버튼이 없다.** 기록 탭에 **[기록 추가]가 없고**, 목록에서 밀어도 수정·삭제가 없다. 휴가 탭에 **휴가 등록 카드와 쉬는 날 입력이 없다.** 설정에 **멤버 추가 등 편집 카드가 없다.**

## C. 반영 확인

### C1. 그룹장이 기록 하나 추가 (PC 일반 창)
1. 서버 그룹을 보는 상태에서 홈의 **[샀어요]**(또는 기록 탭 → 기록 추가 → 저장).
- **성공:** 화면에 바로 반영되고 배너가 잠깐 "저장 중…" → **"그룹장 · 저장됨 ○시"**가 된다. 빨간 오류 배너가 없다.

### C2. 그룹원이 새로고침 후 확인 (시크릿 창)
1. 배너 오른쪽의 **새로고침(↻)**을 누른다. (앱을 다시 열거나 다른 창에 갔다 돌아와도 갱신된다. 실시간 반영은 아직 없다.)
- **성공:** 방금 그룹장이 추가한 기록이 보인다(홈의 "마지막" 날짜나 당번 순서가 바뀌고, 기록 탭에 그날 기록이 생긴다). 배너의 "마지막 업데이트" 시각이 새로 갱신된다. 이 단계에서도 쓰기 버튼은 계속 없다.

## D. (선택) 한 번 더 확인할 것
- 그룹장이 서버 그룹의 휴가/멤버를 하나 고쳐도 같은 방식으로 반영된다.
- 인터넷을 끄면(네트워크 탭 오프라인) 그룹장 화면에 **"인터넷에 연결되면 수정할 수 있어요"**가 뜨고 편집 버튼이 사라지며, 그룹원 화면은 마지막 내용과 **"(연결 안 됨)"**이 보인다.
- 그룹장 로그아웃 → 홈에서 원래 그룹이 **"이전 사본"** 칩으로 돌아오고, 수정하려면 **"서버 그룹에는 반영되지 않아요"** 경고가 뜬다.
